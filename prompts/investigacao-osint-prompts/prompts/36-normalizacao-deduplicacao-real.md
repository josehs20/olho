# Prompt 36 --- Normalização e deduplicação reais

Agora que existem fontes reais, audite o modelo normalizado.

Defina uma chave de deduplicação estável considerando: -
source/platform; - username; - URL canônica quando disponível; - tipo de
entidade.

Não apagar evidências das fontes.

Quando várias fontes encontrarem o mesmo perfil, manter uma descoberta
consolidada com todas as fontes observadoras.

Adicionar testes cruzados entre adapters.

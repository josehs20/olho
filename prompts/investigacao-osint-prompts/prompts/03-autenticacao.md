# Prompt 03 — Autenticação

Implemente os requisitos de `docs/05-autenticacao.md`.

Objetivo: autenticação simples e segura.

Inclua:
- cadastro;
- login/logout;
- confirmação de e-mail;
- recuperação de senha;
- throttling;
- middleware/policy de admin;
- tela básica de perfil/configurações.

Não implementar OAuth, 2FA ou teams.

Crie testes para fluxos positivos e negativos.

Ao final, execute suíte de autenticação e lint.

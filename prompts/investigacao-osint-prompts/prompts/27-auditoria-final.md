# Prompt 27 — Auditoria final do MVP

Faça uma auditoria integral do projeto usando todos os documentos e regras.

Verifique:
1. requisitos implementados;
2. arquitetura;
3. banco;
4. créditos;
5. pagamento fake;
6. autenticação;
7. fila;
8. adapters mock;
9. normalização;
10. deduplicação;
11. correlação;
12. relatório;
13. dashboard;
14. admin;
15. privacidade;
16. segurança;
17. Docker;
18. testes.

Classifique cada requisito como:
- implementado;
- parcial;
- ausente;
- bloqueado.

Depois:
- corrija problemas pequenos e seguros;
- não introduza integrações externas reais;
- rode testes completos;
- rode lint/formatador;
- documente pendências reais para a fase seguinte.

A saída final deve conter:
- resumo do estado;
- arquivos alterados;
- testes executados;
- pendências;
- próximos passos técnicos.

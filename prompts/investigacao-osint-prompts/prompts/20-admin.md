# Prompt 20 — Painel administrativo

Implementar painel admin simples Laravel.

Seções:
- dashboard;
- usuários;
- pacotes;
- pagamentos;
- investigações;
- fontes;
- créditos/ajustes;
- auditoria.

Não instalar pacote de admin se o Laravel atual já permitir implementação simples.

Todo ajuste de crédito exige motivo e audit log.
Criar autorização e testes.

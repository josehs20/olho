# Prompt 38 --- Relatório baseado em evidências

Faça o relatório HTML consumir os dados persistidos do pipeline real.

O relatório deve mostrar: - identificadores pesquisados; - fontes
consultadas; - status de cada fonte; - descobertas; - URLs; - data/hora
de observação; - evidências; - correlações e fatores; - limitações; -
fontes que falharam ou sofreram timeout.

Persistir snapshot somente se isso estiver alinhado ao modelo atual.

Não esconder falhas para aparentar investigação completa.

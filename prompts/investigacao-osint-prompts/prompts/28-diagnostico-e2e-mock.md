# Prompt 28 --- Diagnóstico e E2E com mocks

Analise o estado real do projeto após o Prompt 27.

Não altere código inicialmente.

Verifique Docker, serviços, banco, Redis, filas, workers, scheduler,
rotas, jobs, adapters mock, normalização, deduplicação, correlação,
créditos e relatório.

Monte o fluxo real existente e execute um teste ponta a ponta usando
somente os adapters mock.

Se algo impedir o fluxo, corrija somente o necessário.

Ao final informe: - fluxo executado; - arquivos alterados; - testes
executados; - resultado; - limitações; - commit sugerido.

Não reconstruir funcionalidades existentes.

# Prompt 24 — Hardening de segurança

Auditar o projeto inteiro conforme `docs/15-seguranca.md`.

Verificar:
- auth;
- authorization;
- mass assignment;
- XSS;
- CSRF;
- SQL;
- uploads;
- shell commands;
- webhooks;
- rate limits;
- logs;
- secrets;
- ownership checks.

Criar testes para vulnerabilidades encontradas e corrigi-las.
Não fazer refatorações não relacionadas.

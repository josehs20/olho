# Prompt 01 — Analisar o projeto

Leia `docs/00-visao-geral.md`, `docs/01-requisitos.md`, `docs/02-regras-negocio.md`, `docs/03-arquitetura.md` e as regras `.cursor/rules/*.mdc`.

Objetivo: analisar o repositório atual antes de implementar qualquer funcionalidade.

Tarefas:
1. identificar se o diretório já contém um projeto Laravel;
2. identificar versão do Laravel/PHP;
3. identificar frontend, banco e estado do Docker;
4. listar dependências existentes relacionadas a auth, filas, Redis e testes;
5. apontar conflitos com a arquitetura documentada;
6. propor um plano incremental sem modificar o código, exceto documentação se absolutamente necessário.

Não instalar dependências nem apagar arquivos nesta etapa.

Saída final esperada:
- diagnóstico;
- riscos;
- plano ordenado;
- comandos de validação recomendados.
